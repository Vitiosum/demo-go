Du git push au binaire

Ce que la plateforme a fait pour servir cette page. Aucune dépendance externe : le build ne télécharge rien.

  1. git push clever mainRuntime Go détecté, version lue dans go.mod
  2. go install github.com/Vitiosum/demo-goMéthode gomod, page et CSS embarqués par embed
  3. $GOPATH/bin/demo-goBinaire lancé, écoute sur 0.0.0.0:8080
  4. GET /health → 200Trafic basculé ; SIGTERM à l'arrêt, requêtes terminées
