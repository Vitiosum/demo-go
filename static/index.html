Runtime Go · Bibliothèque standard uniquement

Go, sans dépendance, en production.

Un serveur HTTP écrit avec la seule bibliothèque standard, compilé par Clever Cloud à chaque git push. Aucun Dockerfile, aucune image à maintenir : la plateforme détecte le runtime Go, lance go build et sert le binaire. Les métriques ci-dessous sont celles du processus en train de vous répondre.

  • Build go build automatique
  • Binaire statique
  • HTTPS et domaine inclus
  • Scaling horizontal
